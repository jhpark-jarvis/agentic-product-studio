# History sanitization

이 저장소는 비공개 제품 저장소의 개발 흐름을 포트폴리오로 설명하기 위해 별도의 공개 이력으로 재작성했습니다.

## Preserved

- 커밋 작성자와 작성 시각
- 커밋 순서와 개발 단계
- 문서/WBS/일정/멤버/에셋 관리 구조
- FastAPI, React, SQLite/D1, local/R2 전환 구조
- AI Agent 협업과 문서 기반 컨텍스트 복구 패턴

## Removed or generalized

- 실제 서비스와 프로젝트 이름
- 운영 도메인, IP, 인프라 리소스 식별자와 접근 설정
- 비공개 제품 기획 문서와 실데이터
- 공급자 전용 카탈로그 주소와 원본 데이터
- 로컬 DB, 업로드 파일과 빌드 산출물
- 운영 배포 스크립트와 계정별 구성

파일 내용과 경로가 바뀌어 모든 커밋 해시는 원본과 다릅니다. 정제 대상만 변경한 커밋은 시간 흐름을 보존하기 위해 빈 커밋으로 남을 수 있습니다.
